# FinePrint

**Reads two years of a company's annual report, shows you exactly what changed, and refuses to
accept any quote it cannot find in the filing.**

FinePrint is a company-agnostic pipeline for forensic reading of SEC filings. Give it a ticker (or
two downloaded 10-Ks) and it:

1. fetches the last two 10-Ks from EDGAR,
2. extracts Item 1A (Risk Factors) and Item 7 (MD&A) with a page map computed from the document,
3. diffs them sentence by sentence and ranks the changes by "where findings hide" signals
   (gross-to-net, Medicare negotiation, tariffs/MFN, working capital vs revenue, contingent
   consideration, royalties, litigation, tax, exclusivity, label safety, reclassifications),
4. optionally asks Claude to draft findings from the ranked changes, and
5. runs every quoted finding through a **verification gate**: the quote must string-match the
   source and the page is computed from the document, never generated by a model. Rejections are
   logged, and feed the project's AI errors log.

Built during TCU Neeley's AI Forward competition (Advanced track, "The Fine Print" case). The code
knows nothing about any particular company; it ships with two pre-tested runs, AbbVie (`runs/ABBV`)
and Bristol Myers Squibb (`runs/BMY`).

```
ticker ──> EDGAR (last two 10-Ks) ──> text + page map ──> Item 1A / Item 7
                                                              │
         candidates.md + review.html <── signal ranking <── sentence-level YoY diff
                                                              │
   findings.json (Claude-drafted or human) ──> VERIFICATION GATE ──> verified / REJECTED (+ closest real sentence)
```

## Install

Python 3.10 or newer.

```bash
git clone https://github.com/nwhite9921-lang/fineprint.git
cd fineprint
python3 -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 tests/test_core.py                               # builds a synthetic two-year 10-K and checks diff + gate
```

## Environment variables

| Variable | Needed for | Value |
|---|---|---|
| `FINEPRINT_USER_AGENT` | EDGAR fetch (`run <TICKER>`) | The SEC requires a User-Agent that identifies you, e.g. `"Jane Doe jane@example.com"`. See https://www.sec.gov/os/accessing-edgar-data. The `--user-agent` flag overrides it. |
| `ANTHROPIC_API_KEY` | AI draft step (`draft`) | Your Anthropic API key. Never commit it. `pip install anthropic` is also required for this step. |
| `FINEPRINT_MODEL` | AI draft step (optional) | Model id; default `claude-opus-5-5`. |

```bash
export FINEPRINT_USER_AGENT="Your Name you@example.com"
export ANTHROPIC_API_KEY="sk-ant-..."          # only for the draft step; keep it out of git
```

## Copy-paste commands

### AbbVie (ABBV): fetch from EDGAR, diff, draft, verify

```bash
# 1. Fetch the last two 10-Ks from EDGAR, extract Items 1A and 7, diff, rank, render review.html
python3 -m fineprint run ABBV --out runs/ABBV --user-agent "$FINEPRINT_USER_AGENT"

# 2. Ask Claude to draft findings from the ranked changes, then verify every quote against the filings.
#    Filing paths are printed by step 1 and saved in runs/ABBV/filings.json (local_path).
python3 -m fineprint draft --run runs/ABBV \
  --filing     "$(python3 -c "import json;print(json.load(open('runs/ABBV/filings.json'))[-1]['local_path'])")" \
  --old-filing "$(python3 -c "import json;print(json.load(open('runs/ABBV/filings.json'))[-2]['local_path'])")" \
  --errors-log ERRORS_LOG.md

# 3. Re-render the reviewer page so the drafted findings and their gate results appear
python3 -m fineprint report --run runs/ABBV
open runs/ABBV/review.html       # Linux: xdg-open, Windows: start
```

### Bristol Myers Squibb (BMY): the same three commands

```bash
python3 -m fineprint run BMY --out runs/BMY --user-agent "$FINEPRINT_USER_AGENT"
python3 -m fineprint draft --run runs/BMY \
  --filing     "$(python3 -c "import json;print(json.load(open('runs/BMY/filings.json'))[-1]['local_path'])")" \
  --old-filing "$(python3 -c "import json;print(json.load(open('runs/BMY/filings.json'))[-2]['local_path'])")" \
  --errors-log ERRORS_LOG.md
python3 -m fineprint report --run runs/BMY
```

Any other US filer works the same way: replace the ticker.

### Working offline from downloaded filings

If EDGAR is not reachable from your network, download each 10-K's primary document from the
filing index page (the `.htm`, or print it to PDF) into `filings/` and run with `--local`, oldest
first:

```bash
python3 -m fineprint run --local filings/abbv-20241231.htm filings/abbv-20251231.htm --ticker ABBV --out runs/ABBV
python3 -m fineprint run --local filings/bmy-20241231.pdf  filings/bmy-20251231.pdf  --ticker BMY  --out runs/BMY
```

PDF text extraction takes about a minute per 200-page filing the first time and is cached next to
the PDF (`<name>.fineprint.txt`, git-ignored); reruns take about 20 seconds.

### Verify a single quote, or show the gate catching planted errors

```bash
python3 -m fineprint verify --filing filings/abbv-20251231.htm \
  --quote "In January 2026, Botox was selected as one of 15 medicines subject to government-set prices in Medicare Parts B and D beginning January 1, 2028."

python3 -m fineprint seed-test --filing filings/abbv-20251231.htm \
  --quote "Net revenues for Humira decreased 49% in 2025 primarily driven by continued impact of direct biosimilar competition following the loss of exclusivity."
```

`verify` exits 1 if any quote is rejected, so it can gate a slide build or a CI job. `seed-test`
plants a changed number, a swapped verb and a fabricated clause into a correct quote and shows all
three rejected with the closest real sentence.

### Draft without an API key

```bash
python3 -m fineprint draft --run runs/ABBV --prompt-only     # writes runs/ABBV/draft_prompt.md
```

Paste the prompt pack into any model, save its JSON as `findings.json` (a list of objects with at
least a `quote` field), then run `python3 -m fineprint verify --filing <filing> --findings findings.json`.

## What each output is

| File | What it is |
|---|---|
| `runs/<T>/candidates.md` / `.json` | Ranked changed sentences with verbatim quotes, computed pages, word-level diffs, signals, and cautions |
| `runs/<T>/review.html` | Self-contained reviewer page: approve/reject each item (mouse or keyboard), export decisions as JSON. No network, no tracking. |
| `runs/<T>/diff_item1A.json`, `diff_item7.json` | Full sentence-level diffs |
| `runs/<T>/sections/` | The extracted sections as text (git-ignored; regenerate with `run`) |
| `runs/<T>/findings.json` | Drafted findings with per-quote gate results (git-ignored) |
| `runs/<T>/verification_log.json` | Every `verify` call, pass or fail |
| `ERRORS_LOG.md` | The AI errors log kept during the competition |

## How the pieces work

- `fineprint/edgar.py`: ticker to CIK via `company_tickers.json`, filing list via `data.sec.gov/submissions`, primary document download; stays under the SEC's 10 requests/second.
- `fineprint/extract.py`: HTML/iXBRL to text (hidden XBRL header dropped, tables flattened, page-break elements become form feeds); PDF to text with one form feed per page; PDF text extracts get page breaks rebuilt from printed footers. Browser print headers/footers and folios are blanked before diffing so they never appear in a quote. Sections are located by line-start "Item 1A"/"Item 7" headings; the longest span wins, which discards table-of-contents rows and cross-references.
- `fineprint/diff.py`: sentences aligned with `difflib`; inside replaced blocks, old/new sentences are paired by similarity so an edit shows as one MODIFIED item. Sentences are joined across page breaks first. Anything reported removed or added is searched for in the whole other-year filing; a match is shown as MODIFIED or tagged CAUTION. Pure number roll-forwards are flagged and down-weighted.
- `fineprint/signals.py`: keyword families from the case's "where findings hide" list. Scores rank; they do not decide.
- `fineprint/draft.py`: prompt pack from `candidates.json`, Claude call with a strict JSON schema, then the gate on every quote; the model's page is kept next to the computed page so page errors are visible.
- `fineprint/verify.py`: exact match, then normalized match (smart quotes, dashes, whitespace, line wraps, page breaks, `...` ellipses in order), then nearest-sentence search for the reviewer. Near-misses are REJECTED and shown with the closest real sentence.
- `fineprint/report.py`: renders `review.html`.

## Responsible-AI design, in one paragraph

The model drafts; it never gets the last word. Every quote is checked by string matching against
the source, pages are computed, rejections are logged with the closest real sentence, and a human
approves or rejects each item on the review page. The seeded-error test is run on every demo so
the mitigation is shown, not described. Inputs are public filings; no personal data is processed.
See `ERRORS_LOG.md` for the errors we caught, including two in this tool.

## Limitations

- Sections are found by heading patterns. Filers with unusual headings, or 10-Ks that incorporate
  MD&A by reference to an exhibit, need `--items` or a manual section file.
- The diff is sentence-level; truly reordered paragraphs can still show as removed + added.
- PDF text extraction can merge table columns; quotes from tables may need the `...` form.
- Signals are keyword-based and over-flag routine language; the ranking is a reading order, not a finding.
- The gate verifies that a quote exists and where. It does not verify that the interpretation is
  right. That is the human's job, by design.
- Earnings-call transcripts are not fetched yet; `verify` works on any text file, so a transcript
  saved as `.txt` can be checked today.
